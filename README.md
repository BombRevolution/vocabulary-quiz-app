# vocabulary-quiz-app

一个基于本地词汇库的桌面拼写测试与复习软件。软件给出中文释义和词性，用户拼写英文单词；答对自动进入下一题，答错显示正确拼写并纳入错题复习，适合日常记单词使用。

## 功能

- 拼写测试：显示中文释义和词性，输入英文拼写，回车提交
- 分级判定：分为正确、接近（差一个字母）、错误三个等级
- 错题复习：答错的词当轮稍后重练，下次打开时错题优先复习
- 间隔记忆：按不会、模糊、会、熟练四档状态，配合 1/3/7/30 天复习间隔自动排期
- 每日定量：默认每天学习 200 个新词，可在设置中调整，复习词不设上限
- 多词库独立：支持导入多个词库，各词库学习进度互不影响
- 词库导入：支持 .xls / .xlsx / .csv，自动识别单词列和释义列，兼容有表头和无表头文件
- 词库管理：可重置单个词库的学习进度，也可删除不需要的词库
- 统计面板：显示今日新词进度、待复习数、错题总数、已掌握数
- 跳过/提示：简单词可一键跳过标记为已掌握；难词可按方案（揭示前N%字母/完整拼写/字母个数）提示，快捷键可自定义
- 错题整理：一键查看当前词库不熟练词，并可导出卡片式 PDF 方便打印
- 界面适配：自定义蓝色主题，支持高分屏 DPI 缩放，适配 1080p/2K/2.5K 与 16:9/16:10 等多分辨率比例

## 使用方法

### 直接运行

从 Releases 页面下载 `word-quiz-app.exe`（v1.0.1，即单词拼写测试程序），双击运行，无需安装 Python 环境。

exe 首次运行会在所在目录创建数据文件（vocab.db、config.json），建议放在桌面等可写目录使用。

### 源码运行

需要 Python 3.12 及以上版本。

```
pip install -r requirements.txt
python main.py
```

## 词库格式

支持 .xls、.xlsx、.csv 格式，文件中需要包含至少两列：

| 列 | 说明 |
|----|------|
| 英文单词列 | 存放英文单词，如 apple |
| 中文释义列 | 存放中文释义，如 n. 苹果 |

- 列的位置不限，导入时软件会自动识别哪一列是单词、哪一列是释义
- 如果文件第一行是列名（表头），保持"首行是表头"勾选；如果第一行就是单词数据，取消勾选
- 空单词行会自动跳过，重复单词会自动去重
- 释义会自动提取词性标注（v.、n.、a. 等）

## 目录结构

```
vocabulary-quiz-app/
├── main.py              # 程序入口
├── database.py          # 数据层：SQLite 存取、词库管理
├── importer.py          # 词库解析与导入
├── quiz_logic.py        # 核心逻辑：判定、状态迁移、出题队列
├── ui_main.py           # 主界面
├── ui_quiz.py           # 拼写测试界面
├── ui_import.py         # 词库导入窗口
├── ui_settings.py       # 设置窗口
├── ui_wrongwords.py     # 错题整理弹窗
├── pdf_export.py        # 不熟练词导出 PDF
├── ui_theme.py          # 主题与 UI 组件
├── tests/               # 单元测试
└── requirements.txt     # 依赖清单
```
